# Devlog

## 2026-10-17 — Telegram search, message styling, and stability

### Added
- Telegram global search: debounced search input (400 ms) in the chat list, `BgCommand::SearchChats` / `UiMessage::SearchResults`, results view with chat name + snippet, click to open the chat and scroll to the matched message, and a purple highlight ring around the target message for ~1 s.
- `client::SearchResult` struct and `SearchResult`/`SearchInputChanged`/`SearchResultSelected`/`SearchResults` state-machine events.
- Filename/fallback snippets: search results now show the media file name (or "(no text)") instead of blank lines for caption-less messages.

### Changed
- Self-message bubbles no longer use an accent fill; they use an accent-colored border with white text (play pill switched to black for legibility).
- Message list body now has 12 px horizontal padding; search bar gained 8 px top margin and inner padding.
- Search result snippets are truncated to 46 characters to fit the fixed row height.

### Fixed
- Reverted the message list from `show_rows` (virtualized) back to a plain `ScrollArea::show`, eliminating the row-height-estimate reflow that made bubbles shuffle on every launch.
- Search result click handling no longer borrows the FSM mutably while iterating messages.
